# Architecture rules
- Keep optimization search and pattern feasibility unchanged; apply final-kerf material accounting only after placement to preserve the existing optimum engine.
- SmartCut (modeUltra) has no cap on distinct lengths: a seeded, time-boxed Best-Fit multi-start gives the upper bound, the subset-LP solver runs only up to 8 distinct lengths, and branch-and-bound is bounded by time and patterns per node. Results must stay deterministic for the same input.
- Carry actual start/end margins on each calculated bar, so screen and PDF cumulative dimensions share the same raw-end origin, including stock bars without margins.- Multi-profile optimization runs the unchanged engine once per profile (src/lib/multi-profil.ts) and merges results; screen and PDF iterate `resultat.profils` so each profile keeps its own bar length and subtotal.
- Screen and PDF resolve the same palette from CSS theme tokens via visual-theme.ts; keep export colors centralized to prevent visual drift.
- Result verification lives in src/lib/verification.ts and recomputes everything from the bars without calling the engine, so it can catch engine bugs independently.
- Project backups (.json) carry a format version (src/lib/backup.ts); readers reject newer versions so future formats stay compatible.
- Bar grouping and segment coordinates live in the browser-safe bar-drawing module; screen and PDF consume placed results without changing optimization or verification.
- Adaptive piece labels live in a browser-safe layout module with injected font measurements; screen and PDF share the cascade, consecutive-run row references and physical font sizes to prevent overflow without altering placed cuts.
- Atelier PDF drawings use dynamically loaded svg2pdf.js and SVG geometry; collision-aware dimensions and measured table pagination keep print content legible.
- Embed CDN-hosted Plex Sans font assets exclusively in PDF exports and use tabular digit metrics with explicit per-column alignment shared by headers and values, so workshop printouts remain proportional and aligned.
- Format displayed measurements through the browser-safe format-number module for consistent French screen/PDF labels; keep numeric calculations and editable values unchanged.
- Keep editable-table and measurement-field presentation in shared CSS classes, with shared table-header defaults, so alignment changes do not alter input handlers or calculations.
- Derive material-loss indicators and balanced display percentages in the browser-safe material-summary module shared by screen, PDF and Excel; preserve engine results and independent verification.
- Offcut PDF instructions are optional project fields keyed by normalized profile and exact offcut length (the existing recap row); resolve them only in presentation/export, never in optimization, verification, stock or material accounting.
- Cut method and displayed reuse thresholds live in browser-safe cut-method.ts; thresholds come from computed bars. Screen and tape-measure PDF dimensions filter run ends with rightmost priority; stop-cut PDF dimensions attach to their own brace, reserving its label space before placing unshifted singleton dimensions, independently of full table coordinates.
- Material status is an optional existing-project field normalized and formatted by browser-safe material-status.ts for screen/PDF and JSON compatibility; it never participates in optimization or stock accounting.
- Pieces longer than their profile's usable bar (default or assigned stock) are blocked before optimization by piecesTropLongues in multi-profil.ts, with the field highlighted and a plain-language message; the verification badge stays reserved for engine bugs.
- The result badge ("Résultat optimal" / "Meilleur résultat trouvé") opens a plain-language popover (src/components/QualiteResultat.tsx) showing the absolute minimum (borneMin) and why the result is or is not provably optimal.
- Pasted numbers are read by browser-safe src/lib/parse-nombre.ts: spaces and Swiss apostrophes (' ’ ‘) are thousands separators, comma or point is decimal; pasted lengths under LONGUEUR_SUSPECTE (10 mm) are rejected with a line message instead of being imported silently.
- PDF fonts (IBM Plex Sans, OFL) are bundled in src/assets/fonts and loaded with Vite ?url imports, so PDF export works wherever the app is hosted, with no external asset service.
- Full backup (src/lib/full-backup.ts, pure and tested; config in src/lib/backup-config.ts): the footer "Sauvegarde" link downloads every localStorage key owned by the app into one .json and restores it; restore validates app/kind/version, first downloads the current data as "-avant-restauration", replaces only this app's keys, then reloads. BackupReminder shows a dismissible pill when data exists and the last backup is older than reminderDays (null = no reminder). The same two files are shared verbatim by Linear, Format and Trame.
